# Развёртывание рядом со вторым сайтом

Цель — поднять сайт **изолированно**: свой каталог, свой сервис, своя база,
слушает только `127.0.0.1`. Наружу порт не открывается, поэтому второй сайт,
его веб-сервер и его база гарантированно не затрагиваются. Превью открывается
через SSH-туннель — оно не видно из интернета.

Все команды с `ssh`/`scp` спросят пароль root в терминале — это нормально,
вы у живого терминала.

## 1. Создать каталог на сервере

```bash
ssh root@186.246.10.51 'mkdir -p /opt/gogol'
```

## 2. Скопировать файлы (из корня проекта, на своей машине)

Только то, что нужно в работе (дизайн-референсы из `uploads/` не копируем):

```bash
scp -r app.py db.py schema.sql content.json requirements.txt support.js "Gogol Barbershop.dc.html" admin media deploy root@186.246.10.51:/opt/gogol/
```

## 3. Запустить установку (на сервере)

Порт по умолчанию `8790`; если занят — скрипт остановится и попросит другой.
Свободные порты видно командой `ss -tlnp`.

```bash
ssh root@186.246.10.51 'bash /opt/gogol/deploy/bootstrap.sh'
```

Свой порт или свой пароль админки:

```bash
ssh root@186.246.10.51 'PORT=8791 GOGOL_ADMIN_PASSWORD=ваш_пароль bash /opt/gogol/deploy/bootstrap.sh'
```

Скрипт напечатает пароль админки (если не задан свой) — сохраните его.

## 4. Открыть превью (со своей машины)

Порт наружу закрыт намеренно. Пробрасываем его туннелем:

```bash
ssh -N -L 8899:127.0.0.1:8790 root@186.246.10.51
```

Пока команда висит — сайт на `http://localhost:8899/`, админка `/admin`.

## Обновить сайт после правок

Повторить шаг 2 (файлы перезапишутся) и перезапустить сервис:

```bash
ssh root@186.246.10.51 'chown -R gogol:gogol /opt/gogol && systemctl restart gogol'
```

## Автовыкат из GitHub

Таймер `gogol-deploy.timer` раз в несколько минут дёргает `autodeploy.sh`: если
в `main` появился новый коммит — забирает его, раскладывает по `/opt/gogol`,
перезапускает сервис и проверяет, что сайт отвечает 200. Не ответил — откат на
предыдущий коммит, сайт остаётся живым.

Репозиторий публичный, поэтому клон идёт по HTTPS и никаких ключей и токенов
серверу не нужно. Изначально в скрипте стоял адрес `git@github.com:…`, и выкат
падал на каждом запуске таймера: у root на сервере нет ключа, известного
GitHub. Если репозиторий когда-нибудь закроют, вернуть SSH-адрес и завести
ключ выката (GitHub → репозиторий → Settings → Deploy keys, только чтение).

Проверить и выкатить вручную:

```bash
ssh root@186.246.10.51 'systemctl start gogol-deploy; journalctl -u gogol-deploy -n 20 --no-pager'
```

## Полностью удалить (ничего чужого не заденет)

```bash
ssh root@186.246.10.51 'bash /opt/gogol/deploy/bootstrap.sh --remove'
```

Снимает сервис, свою базу и свою роль. Каталог `/opt/gogol` остаётся — удалить
вручную, если нужно.

## Если хотите сделать превью публичным

По умолчанию оно приватно (только туннель). Чтобы открыть наружу на отдельном
порту, установка запускается с `BIND=0.0.0.0`, и порт открывается в фаерволе
(`ufw allow 8790/tcp`). Это уже видимый снаружи адрес — тогда «скрытности» нет;
для закрытого показа оставайтесь на варианте с туннелем.

## Заметки

- **Postgres** скрипт не ставит и не настраивает намеренно — чтобы не задеть
  конфигурацию второго сайта. Если его нет, скрипт остановится с понятным
  сообщением; установку и настройку Postgres сделайте отдельно.
- Подключиться к серверу по SSH **из среды Claude не удалось**: порт 22 открыт,
  но SSH-рукопожатие с моего адреса отсекается (похоже на fail2ban или фильтр по
  IP). Поэтому установка сделана в виде скрипта, который запускаете вы.
- Пароль root вы прислали открытым текстом в чат — после развёртывания его стоит
  сменить: он осел в истории переписки.
