# Гоголь барбершоп — сайт и админка

Одностраничник барбершопа + админка для правки цен и фотографий.
Контент лежит в PostgreSQL, разметка — в `Gogol Barbershop.dc.html`.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

- сайт — http://127.0.0.1:8123/
- админка — http://127.0.0.1:8123/admin

При первом старте приложение само создаёт базу, накатывает `schema.sql`
и заливает начальный контент из `content.json`.

## Переменные окружения

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `DATABASE_URL` | `postgresql://postgres:postgres@localhost:5432/gogol` | подключение к PostgreSQL |
| `GOGOL_ADMIN_PASSWORD` | `gogol76` | пароль админки (читается один раз, при создании базы) |
| `PORT` | `8123` | порт веб-сервера |

Пароль хранится хешем в таблице `settings`. Чтобы сменить его позже:

```sql
DELETE FROM settings WHERE key = 'admin_password_hash';
```

и перезапустить приложение с нужным `GOGOL_ADMIN_PASSWORD`.

## Что редактируется в админке

| Вкладка | Что меняет |
|---|---|
| Фото | 9 слотов: логотип, 5 картинок главной сетки, «Услуги», «Атмосфера», «О нас» |
| Услуги | три карточки на главной + блок «Комплекс» |
| Прейскурант | группы и строки прайса, порядок, видимость группы |
| Косметика | бренды и позиции |
| Настройки | ссылка «Записаться», показ секции «Косметика» |

Видимые группы прайса делятся пополам: первая половина уходит в левую колонку, вторая — в правую.

Загруженные фото складываются в `media/` и регистрируются в таблице `media`.
Каждое сохранение пишет полный снимок контента в `content_revisions` (хранятся последние 50).

## Оформление админки

Админка сделана по референсу [DESIGN_ADMIN.md](DESIGN_ADMIN.md) — светлая тема Apple:
крупная типографика Inter, чередование полос `#ffffff` и `#f5f5f7` вместо разделителей,
карточки со скруглением 28px без теней и рамок, pill-кнопки, синий `#0071e3` только на
основном действии. Сайт при этом остаётся в своём тёмном барбершоп-стиле — это разные слои.

Одно расхождение с референсом сделано намеренно: там указано
`font-feature-settings: "numr"` «для табличных цифр», но `numr` — это фича числителей
дроби, в Inter она поднимает цифры надстрочно. Используется `font-variant-numeric: tabular-nums`,
то есть то, что имелось в виду по смыслу.

## Структура

| Файл | Роль |
|---|---|
| `app.py` | Flask: отдача сайта, админка, REST API, загрузка файлов |
| `db.py` | подключение к PostgreSQL, чтение и запись контента |
| `schema.sql` | схема базы |
| `content.json` | начальные данные для первого запуска |
| `Gogol Barbershop.dc.html` | разметка сайта (dc-формат, рендерится `support.js`) |
| `admin/` | интерфейс админки |
| `DESIGN_ADMIN.md` | дизайн-референс админки |
| `uploads/` | референсы дизайна, в работе сайта не участвуют |

Данные подставляются в разметку через `window.__GOGOL_CONTENT__`. Захардкоженный
`DEFAULT_CONTENT` внутри `.dc.html` — фолбэк на случай открытия файла без сервера.
